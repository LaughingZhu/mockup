# Code of Conduct

We want this project to be a calm, constructive place to discuss graphics,
geometry, and browser tooling.

Participants must be respectful, assume good faith, give actionable feedback,
and avoid harassment, discrimination, doxxing, or sharing private material.
Maintainers may remove content or pause participation when behavior harms the
community. For a private conduct concern, contact the maintainer through the
[LaughingZhu GitHub profile](https://github.com/LaughingZhu) rather than posting
personal information in a public issue.
