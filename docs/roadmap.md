# Roadmap

## v0.1

- Browser-only core and React editor
- Precomputed depth/mask demo
- Abortable provider seam
- Direct move/resize/rotate
- Shared preview/export renderer
- JSON-safe placement and selection persistence

## Next

- Optional provider reference server with documented response fixtures
- Better candidate visualization and point/exclusion picking
- Worker-backed analysis for large local images
- More synthetic samples: balloon, folded fabric, tapered packaging
- Keyboard-accessible resize and rotation affordances

## Deliberately not promised

- Full 3D reconstruction or hidden-surface completion
- A bundled model, hosted inference endpoint, or credential management
- A production asset store or user-account system
